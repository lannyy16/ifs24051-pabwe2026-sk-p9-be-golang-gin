Pipeline memakai pola Jenkinsfile yang dikirim. Sebelum Deploy, konfigurasi credentials/environment: `URL_REDEPLOY`, `URL_PROGRESS`, `DEPLOY_TOKEN`, `WEBSITE_ID`. Agent memerlukan Docker daemon, container `cicd-jenkins`, network `cicd-network`, plugin Pipeline Utility Steps (`readJSON`) dan Warnings Next Generation (`recordIssues`). Jenkinsfile ini untuk backend Go; frontend dibuild terpisah dengan `npm run build`.
